## 一、arXiv 论文精选（15 篇，挑 5-8 篇最重要的，每篇：一句话贡献点评 + 链接）

本周最集中的方向是**具身智能的世界模型**，其次是**工具调用型 Agent 的权限与评测**，两者正好构成“能力扩张”与“边界收缩”的一对。

1. **VeriTouch: Verified Visuo-Tactile World Models that Improve Robot Policy Learning** — 针对视触觉真机数据“贵且难造”的瓶颈，用可验证的视触觉世界模型来生成或筛选训练信号，相当于把触觉数据从“采集问题”改成“验证问题”。[链接](https://arxiv.org/abs/2611.30572v1)
2. **DexLatentWorld: 3D Cross-Embodiment Latent Action World Models for Zero-Shot Robotic Manipulation** — 在 3D 空间学习跨本体的隐动作表示，让不同机器人/人手数据共享同一动作空间，是零样本操作迁移的关键测试。[链接](https://arxiv.org/abs/2611.30907v1)
3. **World Models as Native Latent Action Models** — 不额外设计动作 token，而是让世界模型本身“长出”隐动作；与上一篇一起，说明 2026 年末的主流做法是**从视频里提取动作**，而不是先定义动作再学动力学。[链接](https://arxiv.org/abs/2611.30898v1)
4. **TrialAgentBench: Evaluating AI Agents for Clinical-Trial Analysis and Long-Horizon Drug-Development Decisions** — 把评测从单轮问答移到“信息要花钱、决策有先后”的长程药物开发场景，这是 Agent benchmark 少见的、带真实成本结构的设定。[链接](https://arxiv.org/abs/2611.30916v1)
5. **SchemaCaps: When a Compatible Tool Update Silently Widens an AI Agent's Authority** — 指出 MCP 工具 JSON schema 的“兼容性升级”会悄悄扩大 Agent 权限，且 8 个受测客户端与扫描器无一识别；“兼容”本身就是攻击面。[链接](https://arxiv.org/abs/2611.30750v1)
6. **Intent-Conditioned Argument Mediation for Tool-Using LLM Agents** — 从 schema 层下沉到参数层，拦截“来源可信但目标越权”的调用（收件人、端点、文件被改写），与 SchemaCaps 互补成一套工具调用授权链。[链接](https://arxiv.org/abs/2611.30745v1)
7. **Auxiliary Clues Aware's Geometry Problem Solving** — 几何题的关键在辅助线构造，把“辅助线索”显式建模进 MLLM 推理链，切中多模态数学最薄弱的一环。[链接](https://arxiv.org/abs/2611.30617v1)
8. **GameDojo: Benchmarking Real-Time Interactive Agents in Video Games** — 强调实时性而非回合制，补上了现有游戏 Agent 评测忽略的延迟与流式决策维度。[链接](https://arxiv.org/abs/2611.30771v1)

其余速览：**MUNDO**（多分辨率时间降尺度生成框架，[链接](https://arxiv.org/abs/2611.30868v1)）、**DyLoMo-DiT**（循环 MoE 扩散 Transformer，[链接](https://arxiv.org/abs/2611.30844v1)）、**Can Multimodal Fusion MakeSense for Embodied Vision in Degraded Sensing?**（传感器退化下的融合鲁棒性，[链接](https://arxiv.org/abs/2611.30836v1)）。

## 二、PubMed 研究精选（15 篇，挑 3-5 篇，一句话说明）

说明：本批仅提供题名与期刊，无摘要，以下判断依据题名，结论需回原文核对。

1. **Aortic stiffness and brain perfusion: a population-based study.**（*Scand Cardiovasc J*）— 把主动脉僵硬度与脑灌注放在同一人群队列里看，是“血管老化→脑小血管病”链条上可验证的一环。[链接](https://pubmed.ncbi.nlm.nih.gov/43049101/)
2. **Brain-computer interfaces in clinical translation: technological advances, clinical practice and future challenges.**（*Cogn Neurodyn*）— BCI 的综述已从“能不能解码”转向“临床怎么落地”，监管、术式与长期随访会成为下一阶段真正的瓶颈。[链接](https://pubmed.ncbi.nlm.nih.gov/43067821/)
3. **Environmental microbial exposure as an under-measured exposome domain: Links to host microbiomes, immune regulation, and disease epidemiology.**（*J Environ Health Sci Eng*）— 点名“环境微生物暴露”是暴露组学里系统性缺失的一块，提示未来队列研究需要补采样而非只补问卷。[链接](https://pubmed.ncbi.nlm.nih.gov/43069764/)
4. **Hydrogen induces microglial M2 polarization and improves neurological outcomes of rats with traumatic brain injury.**（*Med Gas Res*）— 氢气在 TBI 模型里通过小胶质细胞 M2 极化起效，属于低成本干预的高价值机制假设，但动物实验到临床的距离仍很远。[链接](https://pubmed.ncbi.nlm.nih.gov/43062000/)
5. **Beyond Accuracy: Does Disagreement with AI Demonstrate Human Overconfidence?**（*Med Sci Educ*）— 把“人机不一致”直接当作人类过度自信的证据来检验，方法学上值得警惕：不一致也可能只是 AI 错了。[链接](https://pubmed.ncbi.nlm.nih.gov/43069773/)

另可留意：**Ground-truth benchmarking of signed, directed lagged connectivity**（有向滞后连接的基准测试，[链接](https://pubmed.ncbi.nlm.nih.gov/43069791/)）、**Feedback as automatic dose selection in a basal ganglia-thalamocortical model of adaptive DBS**（闭环 DBS 的剂量自选择，[链接](https://pubmed.ncbi.nlm.nih.gov/43069850/)）。
