## 一句话结论

这是一支面向新手的 DeepSeek Harness（DSH）入门教程：先讲清“Agent = Model + Harness”的概念，再说明安装、模型与计费配置、界面与工作区、四种模式与权限，最后用“会议纪要 → 可交互项目进度页”的案例演示 `/plan` 等快捷指令。

## 关键要点

- **[00:43] 核心概念：Agent = Model + Harness。** DSH 是开源的智能体运行时与开发框架。模型负责思考和推理，Harness 负责上下文管理、工具调用与编排、权限审批、会话持久化；两者合起来才能连续干活。视频强调它不是新模型、不是单纯 API 客户端，也不等于网页聊天：网页给“回答”，它给“工作结果”。其理念是“一切皆插件”，模型、工具、界面、存储、安装策略都像乐高积木一样可拼装。
- **[02:48] 安装、模型接入与计费。** 普通用户优先桌面安装包，开发者可用 `npx` 或源码；Windows 安装建议不要放 C 盘（转写为“温度用户”，疑为 Windows 用户，不确定），Mac 要求较少。桌面端登录 DeepSeek 账号后可自动创建 API Key；`npx`/源码方式需自己创建 Key，再到“设置 → 模型管理”配置。也支持第三方 API，模型目录没有的型号要手动添加。费用按 API 用量计，区分缓存命中、缓存未命中和输出，单次成本不稳定；视频称缓存命中率高、总体费用较低，建议先少量充值，赠金政策不确定。
- **[06:08] 界面与工作区。** 左侧是工作区与会话历史，中间是对话区，右上角可打开右侧面板查看文件、任务、浏览器等。工作区相当于 Agent 的“桌面”：它读写哪些文件、在哪个目录跑命令，都由此决定。建议新建专用、干净的文件目录，不要把杂乱文件夹直接作为工作区，以减少干扰和数据泄漏风险。
- **[07:38] 模型选择与会议纪要演示。** 如果 Agent 显得笨或不识图，先检查模型和推理强度；需要识图时要选支持多模态的模型（视频中具体型号转写不清，不确定）。演示中，Agent 读取工作区里的会议记录，按“结论、决议、待办、风险”生成简报，待办要写责任人和截止时间；原始记录还故意混入点外卖等干扰信息。
- **[08:50] 四种 Agent 模式。** 标准模式覆盖日常文件处理、资料整理、写代码，是默认首选；PTC 即 Programmatic Tool Calling，适合写程序批量调用工具，例如处理 100 份会议记录；极简模式只保留少量工具，适合对比测试、减少干扰；“创造/创建”（名称不确定）在标准基础上加入插件管理和开发指引，用于开发插件。模式无好坏，关键是匹配任务。
- **[10:31] 四种权限与风险。** 仅可查看适合读材料、分析给建议，不能改文件；工作区内修改把材料和输出集中在指定目录，便于检查，但不会阻止误改，务必先备份；完全访问减少确认、可执行更多敏感操作，风险更高；Auto Review 会自动审查，但仍是实验性能力，建议观望。视频称日常最常用的是“工作区内修改”。
- **[12:03] 快捷指令与 `/plan` 实战。** 输入 `/` 可查看快捷命令。案例把会议纪要升级成“可按负责人筛选、可点开原文查依据”的项目进度页；先用 `/plan` 让 Agent 给出含验收标准、数据模型、页面设计的计划，确认后再执行，不满意可继续改方案。视频称共 8 个快捷指令，可辨认的有 `/goal`、`/export`、`/file`、`/permission`、`/model`、`/compact`、`/feedback`，加上 `/plan`；拼写和完整名单不确定。
- **[14:32] 结语与下一节。** 案例最终产出可交互网页，说明新手已完成基本上手。作者建议不要只看视频，马上在自己的工作中实践；文档网站和交流群放在评论区，下一节讲插件与 Skill。

## 对个人电脑助手 / DSH 实践

- **先建专用工作区，再谈自动化。** 给 DSH 一个干净、边界明确的本地目录，不要直接拿桌面、下载目录或资料混杂的文件夹开工；重要文件先备份。
- **权限从“工作区内修改”起步。** 读材料、做分析先用“仅可查看”；需要写文件时用“工作区内修改”；“完全访问”只在确实需要更大范围操作时临时开，做完切回低权限。
- **模型按任务配，配完先做连通性测试。** 需要识图就换多模态模型；接第三方 API 时确认模型名已正确添加。配置后用一条短消息测试，报错时依次排查认证、余额、模型和网络。
- **多步骤任务先 `/plan`。** 让 Agent 先交计划，重点看验收标准、数据模型和页面/产出设计，确认后再执行；长任务可用 `/goal`，上下文变长或开始忘事时用 `/compact`。
- **第一个练手任务选低风险文档整理。** 例如“会议纪要 → 结论/决议/待办/风险简报 → 可交互进度页”，既能完整体验读文件、产出和迭代，又便于人工检查。
