# 天枢 · 水墨北斗

桌面图标以纸白衬浓墨，斗柄收笔露出飞白，斗口的四芒星标出天枢。选择窗口把同一颗星放在远山上方，山影以淡墨分出前后，让星图和入口文字保持清晰。星图为北斗示意图。

- `tianshu.ico` 是 Windows 快捷方式图标，含 16、20、24、32、48、64、128、256 像素八档 PNG。16 至 32 像素档加粗斗形并省去山影和飞白。
- `tianshu.png` 是 256 像素图标，`tianshu-seal.svg` 是矢量母版。旧的 `make-icon.ps1` 会用旧图案覆盖 PNG 和 ICO。
- `tianshu-picker.html` 为可离线打开的选择界面设计稿，与两份 SVG 放在同一目录。点击、Tab 和回车可体验选择反馈。`tianshu-picker.png` 是 420 × 320 内容区的两倍分辨率预览，`tianshu-chart.svg` 为独立星图。

原生窗口落地时，第一行接现有天枢启动动作，第二行接 OpenLab。每行右侧放各自的检测状态，初始为“待检测”，随后显示“运行中”或“未启动”。设计稿点击后显示的“已选择”仅用于演示。窗口底色为纸白 `#F7F7F4`，主标题为浓墨 `#1D201E`，辅助文字为墨灰 `#5C605D`。系统标题栏在内容区之外。
