# 天枢 · 北斗星印

桌面图标用朱砂印面承托米白色的斗柄与斗身。斗口的天枢留作四芒星，和选择窗口星图中的朱砂主星对应。星图为北斗示意图。

- `tianshu.ico` 是 Windows 快捷方式图标，含 16、20、24、32、48、64、128、256 像素八档 PNG。小尺寸加粗斗形，并省去边线和星心细节。
- `tianshu.png` 是 256 像素图标，`tianshu-seal.svg` 是矢量母版。旧的 `make-icon.ps1` 会用旧图案覆盖 PNG 和 ICO。
- `tianshu-picker.html` 为可离线打开的选择界面设计稿，与两份 SVG 放在同一目录。点击、Tab 和回车可体验选择反馈。`tianshu-picker.png` 是 420 × 320 内容区的两倍分辨率预览，`tianshu-chart.svg` 为独立星图。

原生窗口落地时，第一行接现有天枢启动动作，第二行接 OpenLab。每行右侧放各自的检测状态，初始为“待检测”，随后显示“运行中”或“未启动”。设计稿点击后显示的“已选择”仅用于演示。颜色取纸白 `#F4EFE4`、松墨 `#30382F`、朱砂 `#B53E2C`。窗口系统标题栏在内容区之外。
