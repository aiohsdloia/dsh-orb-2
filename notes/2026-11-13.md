## Cycle: 第二轮 DSH / DeepSeek 生态调研（butler）

### 目标
为「电脑管家」补齐能力地图与升级清单，允许扩展，参考社区 DeepSeek / DSH 产品。

### 方法
- 读 DSH 官方仓库：MIT、developer preview、everything-is-a-plugin、Web UI 3080。
- 拉取 `awesome-dsh-plugin`：23 分类、10,778 条条目、3,821 个唯一插件。

### 关键发现
- 下载榜说明两个刚需：**插件市场**（`dsh-market` 82k）与**视觉桥**（`modlens` 63k、`vision-router` 21k）。
- 记忆层两个强参考：OpenViking（`viking://` + L0/L1/L2）与 Hindsight（retain/recall/reflect）。
- 调度、报告、视频、远程、渠道、桌面、安全、成本每层都有多个候选，不必自研。
- 飞书桥：`omdsh-dev/dsh-lark`（审批/提问/计划审阅）与 `PlutoKeating/dsh-lark-bot`（流式卡片）比自研 v0 完整。
- 微信读屏是最大风险：微信 PC 自绘控件多，UIA 文本可能不全；应尽早 spike「UIA 导航 + 截图 + OCR/视觉桥」。
- “养鱼”类插件只借机制：生物钟、配额、退避、草稿审批、沉默衰减、账本；不要人格/日记/社交动作。

## Cycle: 调研修正（不依赖飞书；QQ/微信可选；DSH 原生 Computer Use；B 站）

### 修正
- 飞书不是依赖；主入口改为 DSH Web UI + Tailscale/PWA。
- QQ/微信只作为可选 InputAdapter，先留接口；utler/adapters/ 已建。
- 不再把“读微信群”当成核心；wechat-reader 仅参考工具。

### 深度发现
- DSH 源码内置 packages/experimental/tool-computer-use：
  - 13 个 GUI 工具（click/input_text/scroll/hotkey/wait/screenshot/drag/open_app…）；
  - Windows 生产后端（GDI 捕获、SendInput、剪贴板粘贴）；
  - computer-use preset，源码 overlay 挂载；
  - **npm 包不含**，需要源码构建或 DSH Desktop。
- DSH Web：--host/--port/--public-url/--tls-*；无内置鉴权。
- B 站：
  - yt-dlp 元数据可用；样例 BV1kZWX62ENY 无 subtitles/auto captions。
  - --cookies-from-browser edge 失败（浏览器占用 cookie DB）。
  - 音频分段下载 IncompleteRead；需要重试/分片。
  - ffmpeg 已通过 imageio-ffmpeg 可用。
  - 结论：字幕优先但不可依赖；ASR 是主路径。
